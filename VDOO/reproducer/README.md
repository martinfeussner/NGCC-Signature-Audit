# VDOO-128 structural-forgery reproducer

This is the complete source bundle supplied for the paper. It includes the
public-key-only structural attack, the VDOO-128 reference verifier, an
independently seeded public key with no corresponding secret key, and a saved
accepted forgery.

The result targets the sparse coefficient mask generated by the submitted
VDOO-128 implementation. It does not claim an attack against the dense
vinegar-oil layers described by the normative specification and does not use
the separately reported RNG failure.

Requirements are GNU Make, a C compiler, Python 3.10 or later, and NumPy.
First verify the saved evidence, including changed-message and
changed-signature controls:

```sh
./verify_evidence.sh
```

Run the full uncached structural recovery and fresh-message forgery from the
independently seeded public key with:

```sh
./run_full.sh
```

The full attack writes its new evidence under `build/full-attack/`, leaving the
checked artifacts untouched. It took 693.19 seconds on the reported
single-threaded Intel Core i5-6500 system. The detailed component description
is in
[`VDOO_structural_attack/README_REPRODUCE.md`](VDOO_structural_attack/README_REPRODUCE.md).
