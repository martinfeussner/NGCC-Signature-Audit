# BiT-128 global-sign recovery reproducer

`bit_global_sign.c` implements the streaming posterior-weighted ring
regression, the public low-confidence correction search, equivalent-key
completion, and a fresh-message forgery. The secret key generated by the test
harness is used only by the signing-oracle call; the attack never decodes or
compares against it. Success is decided by the compressed public-key relation
and the unmodified verifier. A changed-message control must reject.

Requirements are a POSIX shell, `curl`, `unzip`, `sha256sum`, a C compiler,
and libm. Run the paper's main deterministic experiment with:

```sh
./run.sh 200000 0
```

The script downloads the official BiT archive, requires SHA-256
`698fbe834279a4100a66c20f3e0b634c738e1150936acf74b55efc6db6975e8d`,
and builds against the BiT-128 reference source. You may supply an already
downloaded archive through `BIT_ARCHIVE=/path/to/BiT.zip`.

The paper reports that three of four fixed 200,000-signature trials succeeded;
the fourth succeeded at 250,000. A failed fixed-budget run is therefore an
expected experimental outcome for some key identifiers. To extend a run:

```sh
./run.sh 250000 3
```

The reported 200,000-signature experiment took about 139 single-threaded CPU
seconds on an Intel Core i5-6500. The program streams its statistics and does
not retain the signatures.
